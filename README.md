# 💰 BudgetTrack — Flutter Budget Tracking App

A modern, production-ready personal finance mobile application built with Flutter and Firebase.

---

## 📱 Features

| Feature              | Description                                              |
|----------------------|----------------------------------------------------------|
| Authentication       | Email/password login, signup, forgot password            |
| Dashboard            | Balance summary, income/expense cards, budget alerts     |
| Transactions         | Add / edit / delete income and expense entries           |
| Categories           | Food, Transportation, Bills, Shopping, Salary, Others    |
| Budget Management    | Set monthly limits per category with progress indicators |
| Reports & Analytics  | Pie chart, bar chart, line chart via fl_chart            |
| Dark Mode            | Full light/dark theme with persistent preference         |
| Real-time Sync       | Live Firestore streams — no manual refresh needed        |

## 🔥 Firebase Setup (Step-by-Step)

### Step 1 — Create Firebase Project

1. Go to [console.firebase.google.com](https://console.firebase.google.com)
2. Click **Add project** → name it `budget-tracking-app`
3. Disable Google Analytics (optional for dev) → **Create project**

### Step 2 — Enable Authentication

1. In your Firebase project → **Authentication** → **Get started**
2. **Sign-in method** tab → Click **Email/Password** → Enable → **Save**

### Step 3 — Create Firestore Database

1. **Firestore Database** → **Create database**
2. Select **Start in production mode** (we have our own security rules)
3. Choose your region (e.g., `asia-east1` for Philippines) → **Enable**

### Step 4 — Install FlutterFire CLI

```bash
# Install Dart CLI tool
dart pub global activate flutterfire_cli

# In your Flutter project root:
flutterfire configure
```

Select your Firebase project when prompted. This auto-generates `lib/firebase_options.dart`.

### Step 5 — Add Native Config Files

**Android:** Download `google-services.json` from Firebase Console → Project Settings → Your apps → Android app. Place it at:
```
android/app/google-services.json
```

**iOS:** Download `GoogleService-Info.plist` → Place it at:
```
ios/Runner/GoogleService-Info.plist
```

### Step 6 — Deploy Firestore Rules & Indexes

```bash
# Install Firebase CLI
npm install -g firebase-tools

# Login
firebase login

# Initialize in project root
firebase init firestore

# Deploy rules and indexes
firebase deploy --only firestore:rules
firebase deploy --only firestore:indexes
```

### Step 7 — Android Configuration

Add to `android/build.gradle`:
```gradle
dependencies {
  classpath 'com.google.gms:google-services:4.4.1'
}
```

Add to `android/app/build.gradle`:
```gradle
apply plugin: 'com.google.gms.google-services'

android {
  defaultConfig {
    minSdkVersion 23   // Required for Firebase
  }
}
```

## 📦 Building for Release

### Android APK (Direct install / sideloading)

```bash
# Generate release APK
flutter build apk --release

# Output: build/app/outputs/flutter-apk/app-release.apk
```

### Android App Bundle (Google Play Store)

```bash
# Step 1: Generate keystore (one time only)
keytool -genkey -v \
  -keystore android/budget_app_release.jks \
  -keyalg RSA -keysize 2048 -validity 10000 \
  -alias budget_app_key

# Step 2: Create android/key.properties
# (Never commit this file to version control!)
cat > android/key.properties << EOF
storePassword=YOUR_STORE_PASSWORD
keyPassword=YOUR_KEY_PASSWORD
keyAlias=budget_app_key
storeFile=../budget_app_release.jks
EOF

# Step 3: Update android/app/build.gradle to use key.properties
# (See Firebase Setup Step 7 above)

# Step 4: Build the App Bundle
flutter build appbundle --release

# Output: build/app/outputs/bundle/release/app-release.aab

# Optional: Obfuscate Dart code
flutter build appbundle --release \
  --obfuscate \
  --split-debug-info=build/debug-symbols
```

### iOS (macOS only)

```bash
flutter build ios --release
# Then archive and upload via Xcode Organizer
```

3. **Complete Store Listing:**

   - Feature graphic (1024 x 500 px)

6. **App Releases** → Production → Create new release
7. **Upload** the signed `.aab` file
8. **Review and submit** → Typically 1–7 business days

## 🗄️ Firestore Database Schema

### `users` collection
| Field            | Type      | Description                  |
|------------------|-----------|------------------------------|
| `name`           | String    | User's display name          |
| `email`          | String    | Email address                |
| `currency`       | String    | Currency code (e.g. "PHP")   |
| `createdAt`      | Timestamp | Account creation date        |

### `transactions` collection
| Field              | Type      | Description                      |
|--------------------|-----------|----------------------------------|
| `userId`           | String    | Owner's Firebase UID             |
| `transactionType`  | String    | `"income"` or `"expense"`        |
| `category`         | String    | e.g. "Food", "Salary"            |
| `amount`           | Number    | Positive float value             |
| `description`      | String    | Optional note                    |
| `date`             | Timestamp | Date of transaction              |
| `createdAt`        | Timestamp | Record creation timestamp        |

### `budgets` collection
| Field         | Type      | Description                         |
|---------------|-----------|-------------------------------------|
| `userId`      | String    | Owner's Firebase UID                |
| `category`    | String    | Expense category                    |
| `budgetLimit` | Number    | Monthly spending limit              |
| `month`       | Number    | Month (1–12)                        |
| `year`        | Number    | Four-digit year                     |
| `createdAt`   | Timestamp | Record creation timestamp           |
